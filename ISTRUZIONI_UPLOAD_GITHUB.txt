MEDI TIMER v0.3.0 - AGGIORNAMENTO GITHUB
========================================

1. PRIMA configura la firma stabile seguendo FIRMA_STABILE_GITHUB.txt e usando il pacchetto privato separato MediTimer_FIRMA_STABILE_PRIVATA.zip.
2. Estrai MediTimer_GitHub_v0.3.0.zip sul PC.
3. Nel repository GitHub apri Code > Add file > Upload files.
4. Carica il contenuto estratto sovrascrivendo i file esistenti.
5. NON caricare il pacchetto privato della firma e NON caricare file .jks.
6. Commit changes su main.
7. Apri Actions > Build MediTimer APK.
8. Se il workflow è verde, scarica l'artifact MediTimer-APK.
9. Dentro troverai app-release.apk.

La prima installazione con firma stabile può richiedere la disinstallazione della precedente build debug. Dopo questa prima volta, conserva la stessa chiave e gli aggiornamenti successivi saranno installabili sopra l'app esistente.
