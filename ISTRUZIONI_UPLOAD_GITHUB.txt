MediTimer v0.5.1 - upload GitHub

1. Estrai questo ZIP.
2. Carica/sovrascrivi i file nel repository MediTimer.
3. Verifica manualmente `.github/workflows/build-apk.yml`: deve contenere `gradle :app:assembleRelease --stacktrace`.
4. NON modificare i quattro GitHub Secrets della firma stabile.
5. Fai Commit changes su main.
6. In Actions attendi il workflow verde.
7. Scarica l'artifact `MediTimer-APK`: deve contenere `app-release.apk`.
