MEDITIMER v0.2.0 - AGGIORNAMENTO

1. Estrai completamente questo ZIP sul PC.
2. Apri il repository GitHub MediTimer.
3. Add file -> Upload files.
4. Carica/sovrascrivi il contenuto del pacchetto.
5. Verifica che resti presente anche:
   .github/workflows/build-apk.yml
6. Premi Commit changes.
7. Vai in Actions -> Build MediTimer APK.
8. Attendi il segno verde.
9. Apri il run completato e scarica l'artifact MediTimer-APK.
10. Estrai app-debug.apk e installalo sul telefono.

L'aggiornamento usa lo stesso applicationId, quindi Android dovrebbe proporre l'aggiornamento dell'app esistente mantenendo i dati locali.
