MEDITIMER v0.5.3 — UPLOAD GITHUB

1. Estrai tutto lo ZIP.
2. Carica/sovrascrivi i file nel repository MediTimer.
3. Assicurati che .github/workflows/build-apk.yml resti presente.
4. Il workflow deve compilare:
   gradle :app:assembleRelease --stacktrace
5. Fai Commit changes.
6. Attendi GitHub Actions.
7. Scarica l'artifact MediTimer-APK.
8. Installa app-release.apk.

Versione: 0.5.3
VersionCode: 10
