MediTimer - pacchetto corretto v2
18/09/2026

CORREZIONI PRINCIPALI
- Corretto MediTimerApp.kt: passaggio delle callback refresh con ::refresh.
- Workflow GitHub Actions senza android-actions/setup-android@v3.
- Android SDK 35 installato direttamente tramite sdkmanager.
- Build con JDK 17, Gradle 8.9 e Android Gradle Plugin 8.7.3.

COME AGGIORNARE IL REPOSITORY ESISTENTE
1. Estrarre questo ZIP sul PC.
2. Aprire il repository GitHub ambgl2024-cloud/MediTimer.
3. Add file > Upload files.
4. Trascinare il contenuto estratto (app, gradle e i file nella root).
5. Se Windows non mostra la cartella .github, NON e' un problema: nel repository GitHub esiste gia' il workflow corretto che ha superato gli step SDK/Gradle nell'ultimo run.
6. Commit changes.
7. Il commit avvia automaticamente Build MediTimer APK.
8. Se la build e' verde, aprire il run e scaricare Artifacts > MediTimer-APK.
9. Estrarre l'artifact: contiene app-debug.apk da installare sul telefono.

Se GitHub chiede conferma per sostituire file gia' esistenti, confermare l'aggiornamento.
