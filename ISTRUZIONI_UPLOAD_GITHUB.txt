MEDITIMER v0.4.0 - AGGIORNAMENTO

1. NON modificare i 4 GitHub Actions Secrets già configurati per la firma stabile.
2. Estrai questo ZIP sul PC.
3. Nel repository GitHub MediTimer carica/sovrascrivi il contenuto del pacchetto.
4. Fai Commit changes su main.
5. Vai in Actions e attendi Build MediTimer APK.
6. Se la build è verde, scarica l'artifact MediTimer-APK.
7. Estrai app-release.apk e installalo sopra la versione firmata stabile precedente.

NOVITA PRINCIPALI:
- bip ogni minuto affidabile anche con schermo spento tramite foreground service + wake lock;
- suono finale invariato;
- import CSV del Calendario;
- modalità Aggiungi e Sostituisci storico;
- controllo duplicati e righe non valide;
- modifica/cancellazione eventi storico mantenuta;
- firma stabile invariata.
